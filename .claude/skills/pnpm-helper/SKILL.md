# pnpm Helper

This is a dummy skill for testing purposes.

## Common commands

- Install dependencies: `pnpm install`
- Add a dependency: `pnpm add <package>`
- Add a dev dependency: `pnpm add -D <package>`
- Run the dev server: `pnpm dev`
- Build: `pnpm build`
